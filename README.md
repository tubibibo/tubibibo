### YangoSec — local-first security tooling

Hi, I'm Zzup012. YangoSec is my studio: small tools that run on your own
machine — no account, no cloud service, no telemetry.

**[ReachScope Workbench](https://github.com/tubibibo/reachscope-workbench)** —
Android / Web / Cloud / Host evidence, red/blue review, comparable re-test,
and a human close.

- [Release v0.15.1](https://github.com/tubibibo/reachscope-workbench/releases/tag/v0.15.1)
- [The teaching lab](https://github.com/tubibibo/reachscope-workbench#the-teaching-lab) —
  a real site on loopback: collect, harden, re-test, compare, close.

Next: a red/blue verification layer — authorized, non-destructive actions that
prove impact and carry their evidence. Built on top of the evidence loop,
released when it is real.

What I care about: evidence you can point at afterwards, and saying
"not proven" when something isn't.
